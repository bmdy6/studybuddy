# 配置化：硬编码魔法值整理

> 本事项已并入 `[已验收]配置化-Config与Secret分离.md`，由分支 `refactor/config-settings` 统一实施。普通配置进入 `studybuddy-backend/config.yaml`，不再全部走 `.env`；本文保留为原始盘点记录。

## 背景

2026-07-26 品牌名已完成配置化（见 `[部分实施]品牌-名称配置化与改名.md`）。盘点发现代码里还有一批硬编码的魔法值（超时、分页、种子URL等），本应进配置但散落在各模块。本次把它们统一提到 `settings`，遵循 AGENTS.md「禁魔法值，超时/阈值/重试提取常量或配置」红线。

不影响当前功能正确性，优先级低，可排期做。

## 要配置化的项

| 位置 | 当前硬编码 | 方向 |
|---|---|---|
| `features/question_bank/bili_search_service.py` | `BILI_SEARCH_PAGE_SIZE` / `BILI_SEARCH_TOP_N` / `BILI_SEARCH_TIMEOUT_SEC` 模块级常量 | 提到 `settings`，走 .env |
| `features/question_bank/search_service.py` | 种子 URL 列表（苏州教育网站）硬编码 | 提配置或数据表，换地区可改 |
| `features/question_bank/search_service.py:39` | `_SEARCH_TIMEOUT_SEC = 12` | 提 `settings` |
| `features/question_bank/source_service.py:20` | `_REVIEW_TIMEOUT_SEC = 15` | 提 `settings` |
| `features/agent/agent_loop.py:390` | 工具超时 `timeout=8` | 提 `settings.AGENT_TOOL_TIMEOUT_SEC` |

## 不做（单独排期）

- `studybuddy` 英文标识（域名 `/studybuddy/`、服务器目录、PM2 进程 `studybuddy-api`、vault project key、仓库目录名）--改名涉及部署/nginx/vault/cron，风险高，单独排期。

## 验收标准

1. 上述硬编码全部改为引用 `settings`，`.env.example` 补对应项。
2. 后端 pytest 全过。
3. 改某项配置值，行为按预期变化。
