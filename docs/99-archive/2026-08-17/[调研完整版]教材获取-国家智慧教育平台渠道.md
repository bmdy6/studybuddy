# 教材获取-国家智慧教育平台渠道

## 结论（先行）

**国家中小学智慧教育平台的电子教材可通过其资源 API 免登录获取，已实测下载 2024 新版译林英语七年级上册（27.9MB、166 页、文本型、ISBN 978-7-5753-0036-0）。建议作为知了教材资产库的获取主渠道，配多源降级与开学季重验；渠道是游客态弱鉴权接口，不承诺长期稳定，必须把"已入库资产"与"获取渠道"分层对待。**

## 它是什么

国家中小学智慧教育平台（basic.smartedu.cn，教育部中央电化教育馆运营）的教材栏目（tchMaterial）提供按 2022 年版课程标准修订的电子教材。其资源存储走公开接口：

1. 教材列表页未登录即可见每本教材 URL，URL 含 `contentId`。
2. 资源详情 API（公开、无需登录）：`https://s-file-1.ykt.cbern.com.cn/zxx/ndrv2/resources/tch_material/details/{contentId}.json`
3. 请求头带弱鉴权：`X-ND-AUTH: MAC id="0",nonce="0",mac="0"` + `Authorization: Bearer 0` + `Origin/Referer: https://basic.smartedu.cn`
4. 返回 JSON 的 `ti_items` 中找 `ti_format=pdf` 的 `ti_storages[0]` 直链，GET 下载。

社区工具 [tchMaterial-parser](https://github.com/happycola233/tchMaterial-parser)（5862 stars、MIT、2026-08 仍活跃）封装同一逻辑，可作为降级/参考实现。

## 对知了有什么用（对比现状）

- **现状缺口**：GitHub 教材仓库（TapXWorld/ChinaTextbook 43GB、howdy213/K12-CN-Textbook 37GB 等 8 个仓库）只有 2012 旧版，无 2024 新版；译林教育网电子教材栏目详情页 404；第三方 cccitu.com/smartedu 网页服务 public 直链已 403。
- **本渠道补什么**：官方现行版（2022 课标修订版）教材 PDF，文本型可直接进 pdf-inspector 解析，来源权威。
- **不解决什么**：渠道稳定性（游客态鉴权可能收紧）；教材版权（个人自用不传播，不可作公共分发）。

## 稳定性与更新策略

- **资产稳定**：下载后做 SHA-256/ISBN/页数校验并归档，资产与渠道解耦，不会再消失。
- **渠道风险**：`MAC id="0"` 是游客态空签名，官方加真实 token 校验/IP 限流后失效；cccitu public 域名直链已 403 是先例。对策：主路径 API + 降级路径（tchMaterial-parser / 官方登录 / 人工文档化流程）。
- **教材换版**：教材每年可能更新（2024 版 2025 年仍在印），contentId 会变。对策：开学季重验一次，新 contentId 下载 → 校验 → 新版本记录，旧版本保留并 superseded_by 指向新版，不覆盖不删除。
- **重验节奏**：每学期初一次，不做常驻监控。

## 成本分析

| 成本项 | 说明 |
|---|---|
| 获取脚本 | 一次性 50 行内脚本（contentId → 详情 API → 直链 → 下载 → 校验归档） |
| 每学期维护 | 开学季重验 contentId/渠道，约 30 分钟 |
| 存储 | 每本约 30-50MB PDF + 解析后 Markdown，按需教材量极小 |
| 版权合规 | 个人自用不传播，0 额外成本 |

## 速度

- 单本下载实测 4 秒（27.9MB）；详情 API 秒级返回。
- 解析（pdf-inspector 文本型）实测 7-11ms/份级别。

## 落地建议

教材资产库见功能文档 `docs/11-功能/[未开始]教材-资产库与版本更新.md`：资产模型 + 低频获取脚本 + 版本更新机制 + 多源降级，复用现有 pdf-inspector 与诚实守卫，不做常驻抓取服务。
