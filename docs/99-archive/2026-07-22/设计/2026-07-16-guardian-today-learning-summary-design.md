# 家长今日学习摘要设计

## 目标用户与问题

家长在微信 Bot 询问“孩子今天学了什么、学了多久”时，需要先看到直接结论。当前家长 Agent 会查询宽泛学情并输出投入度、能力值和建议，真实的今日学习事实反而被埋没。

## MVP 行为

- 家长询问今天学习内容或时长时，直接返回确定性今日摘要，不让 LLM 自由扩写。
- 摘要只包含：真实记录的学习时长、今天完成的学习内容、今天仍未完成的计划项。
- 学习时长只采用学生主动记录的 `duration` 学习反馈；计划项的 `minutes` 是预计时间，不能冒充实际学习时长。
- 学习内容复用现有学习计划完成记录、确认笔记、错题和已提交试卷，不新增学习记录表。
- 没有时长时明确说“学习时长暂未记录”；完全没有今日记录时直接说明没有记录。
- 不输出能力值、投入度、泛化建议，也不主动追加“是否制定计划”。

## 架构与数据流

家长微信消息仍先由后端确认渠道身份和绑定学生。`wechat_service` 在已确定学生后识别“今天学了什么/多久”这一窄意图，复用 `growth_summary_service.collect_growth_evidence` 的今日证据，并额外读取今日 `duration` 反馈和未完成今日计划，生成一条短文本；其他家长问题继续走现有只读 Agent。

权限仍由现有家长账号、亲子关系和 `WechatGuardianStudentContext` 校验负责。摘要函数只接收服务端已确认的 `student_id`。

## 失败与空数据

- 亲子关系失效：沿用现有绑定失效处理。
- 无任何今日记录：回复“今天还没有学习记录，学习时长也未记录。”
- 有内容、无时长：列出内容后回复“学习时长暂未记录。”
- 有时长、无内容：只回复真实时长，并说明今天暂未记录具体学习内容。

## 验收

- 原始问题“我小孩学习了多久啊？”默认查询今天并返回短摘要。
- “今天学了什么”返回今天的真实完成内容。
- 不把预计任务分钟数计入实际学习时长。
- 回复不包含投入度、能力值或长篇建议。
- 家长仍只能读取已绑定学生，其他家长问题不受影响。
