# 笔记页默认显示全部笔记设计

## 背景

用户反馈进入“笔记”页面时一开始是空白，但实际之前已经写过每日回顾和普通笔记。当前 `NotesPage` 会收集笔记分类作为筛选标签，不过 `activeCategory=null` 时过滤逻辑等价于“未分类”，导致有分类的笔记默认被筛掉。

## 目标

- 进入 `/notes` 时默认展示全部可见笔记。
- 分类标签只用于收窄结果，不改变默认“全部”视图。
- 真没有笔记时才显示“还没有笔记”；某个分类没有结果时显示“该分类下没有笔记”。
- 保持现有后端 notes API，不新增数据表和接口。

## 非目标

- 不重做笔记页整体视觉。
- 不修改笔记详情页。
- 不处理 Agent 记忆策略；本次只修列表默认视图。

## 设计

前端 `NotesPage` 把 `activeCategory=null` 明确表示“全部”。分类区域新增“全部”标签；选中某个分类时只展示该分类，再点“全部”回到全部笔记。`filteredNotes` 在 `activeCategory` 为空时直接返回 `notes`。

## 验收

- 测试里给两条有分类笔记：`每日回顾` 和 `错题复盘`，进入页面默认能同时看到两条。
- 点击某个分类后只看到该分类笔记。
- 线上/本地浏览器进入学生账号 `/notes`，默认不应因为有分类而空白。
