# Daily Review Clean Checklist Design

## Goal

优化学生端每日回顾页面：界面更简洁，只允许选择回顾日期，目标日期固定为回顾日期后一天；今日目标可以点击完成，完成项显示删除线。

## User Experience

- 页面主任务是快速写完“昨日回顾 + 今日目标”，不做复杂表单。
- 只展示一个可编辑日期：回顾日期。
- 目标日期由回顾日期自动加一天，不提供单独编辑入口。
- 顶部用一行日期摘要展示：`回顾 YYYY.M.D · 目标 YYYY.M.D`。
- 今日目标输入采用“新增目标 + 清单”模型：
  - 输入框写一条目标，点击添加进入清单。
  - 点击清单项切换完成状态。
  - 完成项显示删除线。
  - 保存时未完成项写成 `- [ ] 内容`，完成项写成 `- [x] 内容`。
- “需要督促的地方”保留，但视觉弱化为可选补充。

## Scope

In:
- `DailyReviewPage` 前端体验优化。
- `DailyReviewPage.test.tsx` 覆盖目标日期自动加一天、清单点击完成、保存 checklist。
- `releaseNotes.ts` 增加更新说明。

Out:
- 不新增后端表。
- 不做历史回顾编辑。
- 不把每日目标和学习计划合并。
- 不改笔记详情的 Markdown 渲染。

## Acceptance

- 默认回顾日期是昨天，目标日期自动是今天。
- 修改回顾日期后，目标日期始终自动变成回顾日期 + 1 天。
- 页面不再出现独立“目标日期” DatePicker。
- 今日目标至少一条才允许保存。
- 点击目标项后，该项出现删除线，保存内容包含 `- [x]`。
- Codex 浏览器验收本地和线上页面：文案、日期、清单交互、帮助更新。
