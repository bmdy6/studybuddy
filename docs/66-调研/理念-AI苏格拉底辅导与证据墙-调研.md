## 2. 核心证据

* **Economist 2026-08-18 Does AI stop children from learning?** 引 Chegg 80% 学生已用 AI，NBER 2.6万学生 30月面板：AI 让交作业变快但闭卷不升，说明“替做≠学会”。
* **BestBlogs 2026-08-24 越会用AI的人学习能力退化越快（创业邦）** 作业分/速度涨但闭卷分显著掉，机制是 `认知卸载 + 作业外包 + 跳过生成效应`。
* **推论：** 不是“会用AI就变强”，是“怎么用才不掉”。xcc 现有 `AI出草案→学生必须自己改→再确认入库` 正是卡在“最后一步生成”，强制避免外包。下次理念文案可用：**作业分高≠学会，闭卷分才算**。这与 `待验证≠已掌握` 一致，可作外部背书。

## 4. 代码验收的纠偏

* Simon 8.22 原意：有效用智能体 = 清晰指令 + 自信验证，验证不只有逐行肉眼，`Eyeballing has never been the most effective way`。
* 纠偏：能跑只是及格，**大企业差在好不好读好改**。需双层验：`行为（测试/构建/真机）+ 质量（命名/分层/复用/复杂度/红线四问）`，AI 产出的“能跑但乱”必须靠质量层挡住。
