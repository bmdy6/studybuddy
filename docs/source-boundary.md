# 源码范围

这是现有个人项目主干的干净源码提取，不包含原仓库 Git 历史或未合并功能。

保留完整 `studybuddy-backend/app`、React `src`、公共行为配置、数据结构与通用维护脚本。Agent 循环、工具网关、权限解析、计划草案确认、任务会话、作答判定及未完成任务沿用均沿用原实现。便携化改动集中在配置、可选微信开关、新库初始化和测试隔离。

没有复制学生或家庭记录、照片、真实评估样本、数据库备份、上传目录、公众号二维码、生产日志、账户文档、私有服务器配置、部署流水线或独立微信 Bot 服务。测试数据是代码内构造的合成数据；公开素材目录只含应用图标。

新库初始化额外修正了原 ORM 中未附着到表的主会话唯一索引：将同一学生、同一模式的唯一约束正确创建在 `chat_sessions` 上。历史环境使用过的迁移不在这里自动执行。

首次使用验收还修正了同一身份并发初始化重复建会话、空学习事实反复调用摘要模型，以及素材元数据提示词加载参数错误。身份变化或重置后的迟到请求不能覆盖当前会话；没有学习事实时保留完整摘要状态字段并返回已有确定性空态。

用户已有的家庭目标界面分支等未合并工作不属于本次提取。文档中的能力说明以本仓库当前调用路径为准。
