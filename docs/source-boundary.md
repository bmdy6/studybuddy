# 源码范围与导入原则

本次基于原项目已提交的 `main` 快照 `4c2c984`，通过 Git archive 读取；没有复制 Git 历史、未提交改动或未合并分支。开源基线是 `7f1e31d`。

后端 `app` 与客户端 `src` 已有功能经逐文件比较：保留开源版可选微信开关、模型 provider 配置、主会话唯一索引、并发初始化、空事实摘要、素材提示词和公式渲染修复；没有用旧文件覆盖它们。补齐独立微信 Bot（含测试）、官网独立入口、HobbyBuddy、通用脚本与经筛选的技术文档。HobbyBuddy 的兴趣应用与主应用内的兴趣模式入口各自保留。

不搬私人部署/服务器/CI 配置、私人公众号二维码、真实作答与评估样本、旧家庭默认账号初始化器及其部署测试。原落地页截图来源不可核验，全部替换为本次一次性数据库的合成数据截图。模型和平台的公开官方地址、通用公开资源站点及保留作者署名不属于私人部署配置。

[逐文件导入与未搬清单](source-import-manifest.json) 记录了本次新搬文件及原 main 中缺失但明确排除的每一个文件和原因。既有公开文件有差异时保留公开版本；原仓库未跟踪的 `.env`、数据库、上传、日志等不属于归档输入，未读取或复制。

私有路径和服务域名替换为本机或 `example.invalid`，真实学校示例替换为「示例学校」。导入的历史技术文档只供理解设计，不表示其中的计划都已实施，不继承原环境的验收与部署结论。原有新库初始化只接受空库、不建立默认用户；历史迁移不会自动运行。
